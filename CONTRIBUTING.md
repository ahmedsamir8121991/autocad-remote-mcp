# Contributing

Thanks for helping make AutoCAD Remote MCP better!

## Ways to help

- **Report bugs** with the [bug report form](https://github.com/ahmedsamir8121991/autocad-remote-mcp/issues/new/choose). Include your app version, your AutoCAD version and the exact error message.
- **Suggest tools** with the feature request form: describe the drawing task and the AutoCAD command you'd normally use.
- **Vote on the roadmap.** 👍 the [roadmap issues](https://github.com/ahmedsamir8121991/autocad-remote-mcp/issues?q=is%3Aissue+label%3Aroadmap) you'd use.
- **Share what you drew** in [Discussions](https://github.com/ahmedsamir8121991/autocad-remote-mcp/discussions): prompts, screenshots and workflows help other users.
- **Star the repo** so other AutoCAD users can find it.

## Ground rules

- Never post passwords, pairing codes or screenshots that show them.
- Report security problems privately (see [SECURITY.md](SECURITY.md)), not in public issues.
- Suggestions that would weaken safe mode (free-form commands, LISP, scripts, file access outside the drawings folder) won't be accepted.
